A frame score says that something is wrong.INC says who.

A frame-level detector answers one question: is something wrong now? Three other questions decide whether a detection is usable: which agent is involved, where it is, and how early it could have been flagged. INC (incident detection and anticipation) makes the tracked road agent the unit of prediction. It scores every agent at every frame of a dashcam video and derives the frame score from those per-object scores, so the object-level average precision (AP) against the annotated participants, localization through the agents' masks, and an anticipation reading that asks how early the right agent was flagged all become outputs of the same model.

What the object pathway adds to a strong frame-level model

Fused with a released video foundation model (ViFM) by a rule fixed in advance, the object pathway keeps that model's frame AUC within a point while adding per-object scores, localization and detection of every positive video. Abstract

Frame-level detection of traffic anomalies in dashcam video is now led by video foundation models fine-tuned end to end, but a frame score cannot say which road agent is involved, where it is, or how early it could have been flagged. This paper introduces INC (incident detection and anticipation), an online, object-level pipeline built on frozen foundation models: the released SAM 3.1 segmentation tracker grounds every agent, frozen DINOv3 and V-JEPA 2 encoders describe each agent and the scene, and the Relational Incident Transformer (RIT) — a small factorized transformer of width 128 whose agent–agent attention is biased by pairwise image-plane geometry — scores every tracked agent at every frame; it is the only trained component (about 1.8 M parameters). Two design contributions carry the object pathway: a mask-pooled video-foundation-model node token, which lifts V-JEPA 2's clip representation onto each agent through its segmentation mask (+9.91 object AP), and a fixed-rule fusion with a released frame-level model that keeps its frame AUC within a point (89.3 / 89.0 against 90.0 on DoTA) while adding per-object scores (object AP 50.6), localization (STAUC 57.8 / 60.5) and detection of every positive video. Under a pre-registered, single-variable protocol with paired per-video bootstrap intervals, we then ask what explicit agent–agent attention contributes: +8.97 object AP on context-free per-object features, absorbed (−0.49 [−1.39, +0.41]) once the node carries the mask-pooled video token, with two single-variable controls showing that only a token carrying both the neighbours and their motion makes the block redundant. The block's frame-level contribution transfers to DADA-2000 without retraining (+0.91 [+0.31, +1.49]), and a new participant-anticipation reading shows the video token improving pre-start participant ranking by +5.98 AP. Every number of the paper is reproducible from ledgers of record, and nothing was selected on the test split.

Method

INC builds the object pathway on released models and trains only the incident model. Keeping every encoder frozen isolates the incident model as the single trained variable, so every ablation compares two networks that differ in one named component.

  1. Ground and track every agent. The released SAM 3.1 Object Multiplex tracker, used unmodified behind a frozen output schema, grounds and tracks every agent with six single-prompt sessions per video (person, car, truck, bus, motorcycle, bicycle). Cross-prompt duplicates are collapsed to one masklet per physical object.
  2. Describe each agent with frozen encoders. Each track becomes a per-frame node token: image-plane kinematics, a frozen DINOv3 appearance token of its masked crop, and the mask-pooled V-JEPA 2 video token. Every co-visible pair carries a geometry vector and every frame a scene token.
  3. Score every agent at every frame. The Relational Incident Transformer, a four-block factorized transformer of width 128, alternates causal temporal attention within each track with per-frame agent–agent attention biased by the pair geometry, and emits a score per (agent, frame). The frame score is the maximum over the agents and the scene token, and at evaluation time it is fused with a released, DoTA-fine-tuned ViFM by a rule fixed in advance.

Does explicit agent–agent attention still matter?

It depends on what each agent already carries. Explicit agent–agent attention is worth +8.97 object AP when the node feature is context-free, and it is absorbed, −0.49 [−1.39, +0.41], once the node carries the mask-pooled video token. Its frame-level contribution persists in the object pathway alone, +1.35 [+0.88, +1.82] frame AUC on population (a), and is not measurable once the ViFM frame pathway is fused in.

Two single-variable controls, fixed before any control number existed, change only the clip the token is pooled from: static repeats the current frame (the neighbours, no motion) and crop-tube encodes the agent's own box tube (motion, no neighbours). The block is needed again under both, so only a token carrying the neighbours in motion makes it redundant.

Which agent, and how early

Participant anticipation asks a question only an object pathway can answer: are the agents that will be involved ranked above the others before the incident starts? The mask-pooled video token improves pre-start participant ranking by +5.98 [+4.49, +7.51] APpre1.

Qualitative results

Each clip shows every tracked agent's box coloured by its per-object score, with the score curves of the paper's qualitative figure and a cursor at the current frame. The videos are chosen by the fixed rule of that figure from the per-video score dumps of population (a), not by hand: the best-ranked cases in which a participant is the first agent to cross τ*, within the two seconds before the annotated start, then the rule's first miss and first false alarm.

How the numbers were produced

  • A pre-registered, single-variable ladder. Every architectural step changed exactly one variable, its acceptance margin was signed before its number existed, and its result was read once.
  • Every comparison is paired. Two arms differ in the named component only, are trained under identical pins, seed and caches, are evaluated on the same videos, and are compared with a paired per-video bootstrap of 2,000 resamples.
  • Nothing is selected on the test split. Every INC checkpoint is the final epoch of a fixed recipe.
  • Every number is reproducible. Caches are hashed per video, and every training run and every evaluation was executed twice and required to agree.

Limitations and what is not claimed

  • The pooling grid is coarse for the median dashcam agent: 70.9% of the valid node rows on DoTA and 79.9% on DADA-2000 fall back to the single patch under the mask centroid.
  • The frame pathway is not ours: the released ViFM was trained on every DoTA label and selected on the evaluation split, which is why it is fused at evaluation time with fixed rules.
  • Cost: grounding every agent costs about 43 s per video.

Not claimed: a frame-AUC improvement over the ViFM on DoTA or DADA-2000; any object-level metric on DADA-2000, which has no participant boxes; real-time operation; a decomposition of the mechanism finer than the pre-registered 2 × 2 reading; participant anticipation beyond the paired APpre1 reads.
